# fizz-buzz
Fizz buzz is a group word game for childre to teach the about division.

# Rules
- Numbers divisable by 3 should be returned as "Fizz".
- Numbers divisable by 5 should be returned as "Buzz".
- Numbers divisable by 3 and 5 should be returned as "Fizz Buzz".
